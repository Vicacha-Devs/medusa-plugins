Video y medios 3D, galerías por variante, atributos tipados con normalización SI/Imperial, secciones jerárquicas, insignias y muestras.

## Instalación Rápida

```bash
pnpm add @vicacha-devs/medusa-plugin-product-extensions
```

```ts
// medusa-config.ts
export default defineConfig({
  plugins: [
    {
      resolve: "@vicacha-devs/medusa-plugin-product-extensions",
      options: {},
    },
  ],
});
```
