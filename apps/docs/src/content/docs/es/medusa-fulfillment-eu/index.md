Proveedor de logística UE y Benelux para Medusa v2 compatible con PostNL letterbox, Sendcloud EU y carga paletizada Rotterdam LCL.

## Instalación Rápida

```bash
pnpm add @vicacha-devs/medusa-fulfillment-eu
```

```ts
// medusa-config.ts
export default defineConfig({
  plugins: [
    {
      resolve: "@vicacha-devs/medusa-fulfillment-eu",
      options: {},
    },
  ],
});
```
