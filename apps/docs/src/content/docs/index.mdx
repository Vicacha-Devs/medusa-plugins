## Quick Installation

```bash
# Install any plugin into your Medusa v2 project
pnpm add @vicacha-devs/medusa-plugin-b2b \
  @vicacha-devs/medusa-plugin-documents \
  @vicacha-devs/medusa-plugin-typesense
```
